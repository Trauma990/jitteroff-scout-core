# Security policy

This project is pre-release and receives no security support guarantee yet. Do not put secrets or private targets in profiles or reports. To report a vulnerability privately, open a GitHub private vulnerability report through this repository's Security tab after the public repository is created. If that feature is unavailable, do not post exploit details in a public issue; request a private contact route in a minimal issue.

The CLI is intentionally public-target-only. Requests for private-address or credential bypasses are outside scope.
