# Security policy

This project is pre-release and receives no security support guarantee yet. Do not put secrets or private targets in profiles or reports. To report a vulnerability privately, use **Report a vulnerability** on the [repository's Security advisories page](https://github.com/Trauma990/jitteroff-scout-core/security/advisories). Private vulnerability reporting is enabled. If that flow is unavailable, do not post exploit details in a public issue; request a private contact route in a minimal issue.

The CLI is intentionally public-target-only. Requests for private-address or credential bypasses are outside scope.
