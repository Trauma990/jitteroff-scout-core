# راهنمای فارسی Scout Core

Scout Core یک ابزار محلی و اختیاری برای بررسی محدود میزبان‌های **عمومی** است. فایل پروفایل، نام دامنه و آزمون‌های DNS، اتصال TCP، TLS و HTTP را مشخص می‌کند. ابزار به هیچ سرور خصوصی JITTEROFF وابسته نیست، گزارش را خودکار ارسال نمی‌کند و تنظیمات شبکه را تغییر نمی‌دهد.

این کد هنوز نسخهٔ توسعه‌ای ۰.۱ است. قبل از اجرا، پروفایل را بخوانید و با دستور `plan` شناسه‌ها و اثرانگشت فایل را ببینید. `run` تنها با `--allow-profile-digest` برابر اثرانگشت همان فایل اجرا می‌شود. گزارش می‌تواند زمان‌ها، شناسه‌های عمومی و نشانگرهای آدرس را داشته باشد؛ پیش از اشتراک‌گذاری آن را بازبینی کنید.

برای ساخت و آزمون: `dotnet restore --locked-mode`، سپس `dotnet build --no-restore` و `dotnet test --no-restore`. جزئیات و محدودیت‌ها در [مستند انگلیسی](../README.md) و [وضعیت توسعه](STATUS.md) آمده است.
