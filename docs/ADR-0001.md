# ADR-0001: Independent diagnostic core

Status: accepted for the 0.1 development line.

The existing product's Scout feature is part of a Windows desktop application and includes product-specific capture, archive, operational and upload behavior. Its source is not transferred. This repository uses a clean implementation of narrow public endpoint checks. It neither imports private modules nor takes a build dependency on JITTEROFF services. The product adapter, if any, belongs outside this public repository and requires a separate licensing and security review.

The dependency direction is `Contracts ← Core/Privacy ← Probes/Reporting ← CLI`; tests inject a resolver, address policy and connection factory. Production CLI constructs only the public-address policy. Reporting has no transport dependency. See [threat model](THREAT-MODEL.md).
