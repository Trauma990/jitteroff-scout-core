# JITTEROFF Scout Core v0.1.0

An independent, open-source network diagnostic CLI and .NET 10 library. Scout Core accepts a local profile and performs bounded DNS, TCP, TLS, and HTTP checks against public destinations. It records typed outcomes and exports JSON, HTML, and Markdown reports. It does not depend on JITTEROFF production infrastructure.

## Highlights

- Strict profile validation, explicit file-digest consent, public-address enforcement, and re-resolution before each connection.
- SSRF and DNS-rebinding defenses covered by local security tests.
- No success result for incomplete, unknown, blocked, or inconclusive checks.
- Windows and Linux self-contained CLI packages with SPDX SBOMs and SHA-256 checksum files.

## Getting started

Download the package for your platform and extract it. Review the included `public-web.json` profile before running a probe. On Windows, run `Scout.Cli.exe plan public-web.json`; on Linux, run `./Scout.Cli plan public-web.json`. The `plan` command makes no network request to the endpoint. See the [README](https://github.com/Trauma990/jitteroff-scout-core#readme) for the explicit digest-consent step before `run`.

## Verification and limits

The release workflow tests the locked source on Windows and Ubuntu, validates both SPDX SBOMs and ZIP checksums, and runs the downloaded Windows executable in a pinned Nano Server container without the .NET SDK or runtime. It re-downloads the draft Release assets and checks their contents before publishing. The source commit, workflow run, and per-archive SHA-256 values are appended below by that workflow.

TLS checks validate hostname and chain but do not check online certificate revocation. System DNS cancellation may be delayed by the operating system.
