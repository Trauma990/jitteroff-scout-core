# Development status — 2026-11-21

Implemented in the initial 0.1 development stage: independent .NET 10 solution, strict profile parsing, public-address gate, opt-in digest, DNS/TCP/TLS/HTTP probes, typed results, report consistency checks, JSON/HTML/Markdown output, report diff, and local security unit/integration tests.

The [public development repository](https://github.com/Trauma990/jitteroff-scout-core) is live. [Windows and Ubuntu CI on merged main](https://github.com/Trauma990/jitteroff-scout-core/actions/runs/44837977424) passed build and tests on both platforms. See the [publication evidence](evidence/2026-11-20-stage-3-publication.md).

The [final 0.1.0 package run](https://github.com/Trauma990/jitteroff-scout-core/actions/runs/44838015720) on merged-main commit `c289b2c` passed Windows and Ubuntu packaging, SPDX validation, ZIP checksums, and a clean Windows smoke test in a pinned Nano Server container without .NET SDK or Runtime. I independently downloaded both final archives and verified their checksums, component lists, and Windows Library License text. .NET runtime and SDK versions are pinned to the 10.0.15 security servicing release. Earlier 10.0.11 candidates are obsolete. Publisher review of the Windows .NET Library License terms remains required before distributing the Windows binary. The current implementation has no online certificate revocation check. System DNS cancellation can be delayed by the operating system. Do not market these gaps as complete.

The [2026-11-21 review remediation](evidence/2026-11-21-review-remediation.md) fixes interim HTTP response handling, caller-built profile validation, exact IPv4 prefix checks, report metadata requirements, and locked self-contained restore for both targets. The downloaded `b7844a7` ZIP checksums were independently verified. Each curated SPDX SBOM identifies Scout Core, its target 10.0.15 runtime, and the native app host. The Windows archive includes the verified .NET Library License text in addition to the runtime pack's MIT text and notices. File-level SBOM conclusions remain `NOASSERTION` for mixed-license binaries.

Stage 1: contract and runnable vertical slice with [local evidence](evidence/2026-11-20-stage-1.md). Stage 2: adversarial fixtures, schema artifact and report validation hardening with [local evidence](evidence/2026-11-20-stage-2.md). Stage 3 has public source, cross-platform CI, wire-level SSRF/rebinding tests, deterministic privacy/result fuzzing, final package validation, and a clean Windows container smoke test. The [opt-in release workflow](../.github/workflows/package-candidate.yml) publishes only after those jobs pass and then downloads the draft Release assets to check their checksums before public release. [Release issue #3](https://github.com/Trauma990/jitteroff-scout-core/issues/3) tracks publisher review and publication.
