# Development status — 2026-11-20

Implemented in the initial 0.1 development stage: independent .NET 10 solution, strict profile parsing, public-address gate, opt-in digest, DNS/TCP/TLS/HTTP probes, typed results, report consistency checks, JSON/HTML/Markdown output, report diff, and local security unit/integration tests.

The [public development repository](https://github.com/Trauma990/jitteroff-scout-core) is live. The latest [Windows and Ubuntu CI run for the security fixtures](https://github.com/Trauma990/jitteroff-scout-core/actions/runs/44781192938) passed build and tests on both platforms. See the [publication evidence](evidence/2026-11-20-stage-3-publication.md).

**Not yet accepted as a public 0.1 release:** expanded report privacy fuzzing, clean no-SDK Windows install test, and checksummed release artifacts with an SBOM. Fresh staged-file checkouts on Windows and Ubuntu (WSL) build and pass 41 tests; the Linux public sample run also completes. A self-contained Windows executable runs with .NET removed from `PATH`, but the build machine still has an SDK. TLS hostname, expiry, chain, HTTPS redirects, header limits, cancellation and total-budget exhaustion have deterministic local integration fixtures. A local UDP DNS server and real TCP socket now test rebinding and mixed answers. The current implementation has no online certificate revocation check. System DNS cancellation can be delayed by the operating system. These gaps are tracked in the staged plan below; do not market them as complete.

Stage 1: contract and runnable vertical slice with [local evidence](evidence/2026-11-20-stage-1.md). Stage 2: adversarial fixtures, schema artifact and report validation hardening with [local evidence](evidence/2026-11-20-stage-2.md). Stage 3 is in progress: public source, cross-platform CI and wire-level SSRF/rebinding tests are verified; [privacy fuzzing](https://github.com/Trauma990/jitteroff-scout-core/issues/2) and [clean-install/release review](https://github.com/Trauma990/jitteroff-scout-core/issues/3) remain. Every stage needs passing evidence before its status changes.
