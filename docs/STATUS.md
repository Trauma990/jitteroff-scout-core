# Development status — 2026-11-21

Implemented in the initial 0.1 development stage: independent .NET 10 solution, strict profile parsing, public-address gate, opt-in digest, DNS/TCP/TLS/HTTP probes, typed results, report consistency checks, JSON/HTML/Markdown output, report diff, and local security unit/integration tests.

The [public development repository](https://github.com/Trauma990/jitteroff-scout-core) is live. The [latest Windows and Ubuntu CI run](https://github.com/Trauma990/jitteroff-scout-core/actions/runs/44831960917) passed build and tests on both platforms. See the [publication evidence](evidence/2026-11-20-stage-3-publication.md).

The [latest candidate run](https://github.com/Trauma990/jitteroff-scout-core/actions/runs/44836106298) on commit `b7844a7` passed Windows and Ubuntu packaging, SPDX validation, ZIP checksums, and a clean Windows smoke test in a pinned Nano Server container without .NET SDK or Runtime. The [same commit's CI](https://github.com/Trauma990/jitteroff-scout-core/actions/runs/44836094432) passed on both platforms. .NET runtime and SDK versions are pinned to the 10.0.15 security servicing release. Earlier 10.0.11 candidates are obsolete. Final release packaging and publisher review of the Windows .NET Library License terms are still required before a stable tag. The current implementation has no online certificate revocation check. System DNS cancellation can be delayed by the operating system. Do not market these gaps as complete.

The [2026-11-21 review remediation](evidence/2026-11-21-review-remediation.md) fixes interim HTTP response handling, caller-built profile validation, exact IPv4 prefix checks, report metadata requirements, and locked self-contained restore for both targets. The downloaded `b7844a7` ZIP checksums were independently verified. Each curated SPDX SBOM identifies Scout Core, its target 10.0.15 runtime, and the native app host. The Windows archive includes the verified .NET Library License text in addition to the runtime pack's MIT text and notices. File-level SBOM conclusions remain `NOASSERTION` for mixed-license binaries.

Stage 1: contract and runnable vertical slice with [local evidence](evidence/2026-11-20-stage-1.md). Stage 2: adversarial fixtures, schema artifact and report validation hardening with [local evidence](evidence/2026-11-20-stage-2.md). Stage 3 has public source, cross-platform CI, wire-level SSRF/rebinding tests, deterministic privacy/result fuzzing, candidate packaging, and a clean Windows container smoke test. [Release issue #3](https://github.com/Trauma990/jitteroff-scout-core/issues/3) tracks final publisher review, tagged artifacts, and download verification.
