# Development status — 2026-11-21

Implemented in the initial 0.1 development stage: independent .NET 10 solution, strict profile parsing, public-address gate, opt-in digest, DNS/TCP/TLS/HTTP probes, typed results, report consistency checks, JSON/HTML/Markdown output, report diff, and local security unit/integration tests.

The [public development repository](https://github.com/Trauma990/jitteroff-scout-core) is live. The latest [Windows and Ubuntu CI run for the security fixtures](https://github.com/Trauma990/jitteroff-scout-core/actions/runs/44781192938) passed build and tests on both platforms. See the [publication evidence](evidence/2026-11-20-stage-3-publication.md).

**Not yet accepted as a public 0.1 release:** a clean no-SDK Windows install test and final licensing/release review. The review-remediation code commit `260619e` passed [Windows/Ubuntu CI](https://github.com/Trauma990/jitteroff-scout-core/actions/runs/44828471884) and [candidate packaging](https://github.com/Trauma990/jitteroff-scout-core/actions/runs/44828879276) on both platforms. The local Windows branch passes 61 tests. I downloaded both candidate artifacts, matched their inner ZIP checksums, and ran the downloaded Windows CLI's offline plan command on this developer host. It still has an SDK, so that is not a clean-host test. These are short-lived candidates, not a tagged release. The current implementation has no online certificate revocation check. System DNS cancellation can be delayed by the operating system. These gaps are tracked in the staged plan below; do not market them as complete.

The [2026-11-21 review remediation](evidence/2026-11-21-review-remediation.md) fixes interim HTTP response handling, caller-built profile validation, exact IPv4 prefix checks, report metadata requirements, and locked self-contained restore for both candidate targets. Runtime pack license and third-party notices are copied into each new candidate archive. SBOM license fields remain `NOASSERTION`; a final per-archive license review remains a release gate.

Stage 1: contract and runnable vertical slice with [local evidence](evidence/2026-11-20-stage-1.md). Stage 2: adversarial fixtures, schema artifact and report validation hardening with [local evidence](evidence/2026-11-20-stage-2.md). Stage 3 is in progress: public source, cross-platform CI, wire-level SSRF/rebinding tests, deterministic privacy/result fuzzing and candidate packaging are verified; [clean-install/licensing/release review](https://github.com/Trauma990/jitteroff-scout-core/issues/3) remains. Every stage needs passing evidence before its status changes.
