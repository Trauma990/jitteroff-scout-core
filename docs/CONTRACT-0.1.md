# Version 0.1 contract

Profile JSON must be UTF-8, at most 128 KiB, depth at most 16, with no duplicate or unknown keys. Root fields: `schema_version: "0.1"`, `profile_id`, `profile_version` (three numeric parts) and `endpoints` (1–10). Each endpoint has a unique public `endpoint_id`, lowercase ASCII/Punycode DNS `host`, `port` (1–65535) and an ordered unique prefix of `dns,tcp,tls,http`. HTTP additionally requires `http_method` (`HEAD` or `GET`), `http_path` (absolute path, no query/fragment) and `expected_status` (1–6 distinct final HTTP codes from 200–599). IDs are public, max 64 characters, and should contain no personal data.

`run` requires the SHA-256 of the exact validated file bytes. Samples are 1–3, sequential in 0.1 (within the concurrency ceiling of 2). DNS, TCP, TLS and HTTP each have budgets of 5, 3, 5 and 8 seconds; the run budget is 90 seconds. A timeout is an observed failure; exhausted total budget yields `partial` and `budget_exhausted`. Dependency failures produce explicit `skipped` checks. Cancellation yields `cancelled`.

Checks report `pass`, `fail`, `inconclusive`, `blocked`, `skipped` or `cancelled` with a typed reason. DNS returns only address family and per-run HMAC address token. TCP probe duration includes DNS re-resolution, address validation and connection; it is **not game ping**. TLS validates certificate name and chain, without online revocation (`revocation_check: not_performed`). HTTP uses HTTP/1.1 with the original hostname for SNI and Host, a pinned validated address, no proxy and no redirect following. It records the final status only, never response body. Informational responses share the 16 KiB cumulative header budget; more than eight or a `101 Switching Protocols` response fail without a final status.

The report has its own `schema_version: "0.1"`, report ID, tool version and commit (`unknown` in local builds unless `ScoutCommit` is supplied at build time), profile IDs and digest, UTC start, duration, platform, policy version, sample count, `aggregation: none`, run status, planned checks, check results and a privacy summary. CI supplies its Git commit SHA. JSON reports are capped at 2 MiB; imported reports must include every required field and cannot contain null checks. A `complete` run must account for every planned check and every requested sample and cannot contain blocked or inconclusive checks. An empty DNS answer during any probe is a recorded `fail/dns_no_answer`, including re-resolution after an earlier pass. Diff requires matching profile ID, exact digest and policy version; it never infers cause or overall improvement.

The network policy version is `public-address-v2`. It applies IANA's non-global default for `2001::/23` with only its explicitly global suballocations allowed. Reports created with an earlier policy version remain intact, but this version does not compare them directly with new reports.

No promise is made about endpoint service quality or a user's application. This is a diagnostic observation tool, not a repair or bypass tool.
